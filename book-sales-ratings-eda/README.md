# Book Sales & Ratings — Exploratory Data Analysis (EDA)

An exploratory data analysis project investigating book ratings, publication years, languages, genres, authors, publishers, and sales-related patterns using Python.

## Project Overview

This notebook explores a cleaned books dataset to understand its structure, check data quality, and visualize patterns across book-related features.

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Kaggle

## Analysis Covered

- Dataset overview and descriptive statistics
- Missing-value and duplicate checks
- Exploration of unique values and book attributes
- Publication-year distribution
- Genre and language distributions
- Average book ratings by author
- Relationships between ratings, prices, and units sold
- Publisher and author sales/revenue summaries
- Box plots and yearly sales trends
