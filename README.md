# EDA Projects 📊

A collection of **Exploratory Data Analysis (EDA)** projects using Python to explore real-world datasets, clean data, identify patterns, and communicate insights through visualizations.

## 🛠️ Tools & Technologies

- **Python** — Data analysis and programming
- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical computing
- **Matplotlib** — Data visualization
- **Jupyter Notebook** — Interactive analysis

## 📂 Projects

### 1. Book Sales & Ratings EDA 📚

An exploratory data analysis project focused on book sales, ratings, authors, publishers, publication years, and languages.

**Key Activities:**
- Inspected dataset structure and data types
- Checked for missing values and duplicate records
- Explored publication-year and language distributions
- Analyzed book ratings and sales patterns
- Compared author and publisher statistics
- Created visualizations to identify trends and relationships

**Project Files:**
- `Book_EDA.ipynb` — Jupyter notebook containing the analysis
- `Books_Data_Clean.csv` — Dataset used in the project

**Technologies:** Python, Pandas, NumPy, Matplotlib, Jupyter Notebook

## 🚀 How to Run a Project

1. Clone this repository:

   ```bash
   git clone https://github.com/aaravpandey198/eda-projects.git
   ```

2. Navigate to the project folder:

   ```bash
   cd eda-projects/book-sales-ratings-eda
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib jupyter
   ```

4. Open the notebook:

   ```bash
   jupyter notebook Book_EDA.ipynb
   ```

5. Run the notebook cells to explore the analysis and visualizations.
